# JI SU HUAN YU TECHNOLOGY — GitHub Pages

这是一个零依赖的静态展示网站，直接由 `index.html`、`styles.css` 和 `assets/` 构成。

## 发布到 GitHub Pages

1. 新建一个 GitHub 仓库，例如 `jisu-huanyu-website`。
2. 将本目录内的所有文件上传到仓库根目录并推送到 `main` 分支。
3. 在 GitHub 仓库的 **Settings → Pages** 中选择：
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
4. 保存后，GitHub 会提供 Pages 网址。

本版本为纯前端展示页：没有表单、数据库、追踪代码或第三方脚本。
